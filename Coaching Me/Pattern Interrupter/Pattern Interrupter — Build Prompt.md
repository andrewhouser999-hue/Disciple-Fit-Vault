# Pattern Interrupter — Build Prompt

*This is a design-proposal/satellite document, like [[Lie Eliminator & Identity Installer — Adaptation Over Time (Design Proposal)]] — not itself a working tool, but the spec behind one. Read this before extending Pattern Interrupter with a new entry type, a new field, or a second client-facing variant.*

---

## What this tool is for

[[Lie Eliminator - Personal]] works on **belief** (a false claim about God/self/reality). [[Identity Installer - Personal]] works on **self-concept** (an old identity pattern replaced by a true one). Neither has a slot for an **inherited relational script** — an automatic sequence of action, learned by watching it modeled, that fires on another person before conscious values get a vote. That gap is what Pattern Interrupter targets. It sits in the same three-tool family and shares their conventions (This Activates When, Holding Both, phase tracking) but adds two fields neither sibling tool needed, because this is the first tool in the system that acts on someone else: **Whose Script This Is** (naming the source) and **The Repair Step** (what to do when the old pattern fires anyway, on a real person, in real time).

---

## Full field list and why each one exists

1. **This Activates When** — Beck's ABC model; same as both sibling tools.
2. **Whose Script This Is** — Bowen's multigenerational transmission process; converts "my character" into "inherited material," the same move Lie Eliminator's lie-archaeology makes for beliefs.
3. **Wound or Gap?** — design judgment (not itself sourced), but load-bearing: determines whether grief-and-re-securing or modeling-and-repetition gets the emphasis in the fields that follow.
4. **The Old Script — Step by Step** — Siegel & Hartzell (implicit memory / procedural reenactment). Must be a sequence, not a single statement, or it's too vague to interrupt mid-run.
5. **What This Script Gives Me** — secondary gain; Miller & Rollnick. Same rationale as Lie Eliminator's "What Does That Lie Give You."
6. **5b-i. Internal Cost (to me) — Past/Present/Future** — Fonagy (reflective functioning: self-mentalization precedes accurate other-mentalization — this is *why* it has to come before 5b-ii, not just be adjacent to it); Prochaska & DiClemente (decisional balance — cons of the old behavior, tracked as its own construct); Oettingen (mental contrasting supplies the Future slot).
7. **5b-ii. External Cost (to the other person/relationship) — Past/Present/Future** — same Prochaska/Oettingen mechanism turned outward; Baumrind and Gershoff & Grogan-Kaylor ground the *content* of what's actually being risked in documented outcomes, not generic guilt.
8. **The Desired Script — Step by Step** — Ecker/Ticic/Hulley (a vague ideal can't out-compete a vivid automatic pattern — needs matched specificity); Fonagy again (the capacity being rehearsed is reflective functioning in the live moment).
9. **Anchor Identity** — cross-link to Identity Installer; Kegan & Lahey's Big Assumption logic — the new script has to run from a secured identity or it collapses under pressure.
10. **Holding Both — In the Body** — identical mechanism to both sibling tools: Ecker/Ticic/Hulley, Ogden & Fisher, Fosha, Gendlin.
11. **The Repair Step** — Tronick's rupture-and-repair research: secure attachment is predicted by reliable repair after misattunement, not by its absence. This is the field that makes the tool honest about relapse, and the one genuinely novel structural addition beyond field 2.
12. **Witness** — Johari Window / Proverbs 12:15 / Hebrews 3:13; same as Lie Eliminator's "What Others Observe," but the witness must be a peer adult, never the person the pattern acts on.
13. **Rehearsal / Phase Tracking** — reuses Identity Installer's Active → Integrating → Integrated design directly.

## Sequencing rule (don't collapse this)

5b-i must be completed before 5b-ii, every time — not just listed in that order on the page. The reasoning: assessing cost to another person accurately requires the self-mentalizing capacity that 5b-i builds first (Fonagy), and surfacing the external cost before the internal one risks landing as externally-imposed guilt rather than self-generated motivation (Miller & Rollnick's discrepancy-development principle) — which is especially dangerous when the pattern being worked *is itself* a punitive/judgment-first script, since guilt-first framing can re-trigger the exact structure the tool is trying to dismantle.

## Personal vs. client-facing: what has to differ

- **Personal** (`Coaching Me/Pattern Interrupter/Pattern Interrupter - Personal.md`): first-person, pre-filled with Andrew's actual material where it's already known, blanks left as prompts only where the specific answer is still his to locate. Field names can carry full clinical/theological precision (e.g., "Wound or Gap?" stated exactly as the diagnostic term).
- **Client-facing** (`Coaching/Coaching Preparation/Session — Active/Client Tools/Pattern Interrupter — Client Workbook.md`): generalized to any relational context, not parenting-specific. Every field gets a "What it is / What to do" explainer, matching the Identity Installer Client Workbook's instructional voice. Carries an explicit non-clinical boundary statement and a referral cue (flashbacks/danger-level material → name it to the coach, this tool doesn't cover it). Includes one fully worked fictional example before the blank template, per the sibling workbooks' convention.

## If extending this tool later

- A new entry in the Personal doc follows the same 11 (13-including-split) fields in order — don't skip 5b's internal-before-external sequencing even for a less loaded pattern.
- If a fourth tool is ever proposed, check first whether it's really a new *layer* (belief / identity / relational script are the three found so far) or just a variant of one of these three — don't create a fourth field-set without first confirming the existing three don't already cover it.
- The phase-tracking system (Active/Integrating/Integrated) is inherited, not reinvented — if Identity Installer's phase design changes, Pattern Interrupter's should be revisited for consistency, and vice versa.
