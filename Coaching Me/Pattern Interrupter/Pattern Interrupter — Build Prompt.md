# Pattern Interrupter — Build Prompt

*This is a design-proposal/satellite document, like [[Lie Eliminator & Identity Installer — Adaptation Over Time (Design Proposal)]] — not itself a working tool, but the spec behind one. Read this before extending Pattern Interrupter with a new entry type, a new field, or a second client-facing variant. For the full clinical-protocol mapping (Habit Reversal Training, DBT chain analysis, Schema Therapy mode work, Marlatt's Relapse Prevention Model) and honestly-named limitations, see [[Pattern Interrupter — Clinical Basis & Design Rationale]].*

---

## What this tool is for

[[Lie Eliminator - Personal]] works on **belief** (a false claim about God/self/reality). [[Identity Installer - Personal]] works on **self-concept** (an old identity pattern replaced by a true one). Neither has a slot for an **inherited relational script** — an automatic sequence of action, learned by watching it modeled, that fires on another person before conscious values get a vote. That gap is what Pattern Interrupter targets. It sits in the same three-tool family and shares their conventions (This Activates When, Holding Both, phase tracking) but adds fields neither sibling tool needed, because this is the first tool in the system that acts on someone else: **Whose Script This Is** (naming the source), **The Repair Step** (what to do when the old pattern fires anyway, on a real person, in real time), and — added 2026-09-06 after /scrutinize — **What Am I Trusting Instead?** (the biblical-counseling diagnostic layer this tool needs since it's designed to function as a standalone client-facing diagnostic, not only downstream of [[09 — Functional Savior Audit]]).

## Full field list and why each one exists (current order — reordered 2026-09-06)

1. **This Activates When** — Beck's ABC model; same as both sibling tools.
2. **Whose Script This Is** — Bowen's multigenerational transmission process; converts "my character" into "inherited material," the same move Lie Eliminator's lie-archaeology makes for beliefs. Carries Ezekiel 18:20 as its scriptural grounding (added 2026-09-06) — a pattern handed down does not have to be handed on.
3. **Wound or Gap?** — design judgment (not itself sourced), but load-bearing: determines whether grief-and-re-securing or modeling-and-repetition gets the emphasis in the fields that follow.
4. **The Old Script — Step by Step** — Siegel & Hartzell (implicit memory / procedural reenactment). Must be a sequence, not a single statement, or it's too vague to interrupt mid-run.
5. **What This Script Gives Me** — secondary gain; Miller & Rollnick. Same rationale as Lie Eliminator's "What Does That Lie Give You."
6. **What Am I Trusting Instead? (Functional Savior Diagnostic)** — added 2026-09-06. Keller's functional-savior framework and Tripp's heart-behavior model. Sits directly after secondary gain: field 5 names the psychological payoff, field 6 asks the theological question underneath it. Without this field, HRT's behavioral mechanics could interrupt the pattern while the functional idol driving it goes untouched — this field is what keeps the tool a formation instrument, not pure behavior modification. Cross-references [[09 — Functional Savior Audit]] for deeper excavation rather than duplicating it.
7. **What This Script Costs — 7a (Internal, to me) then 7b (External, to the other person/relationship), Past/Present/Future** — one wrapped field, two ordered parts, not two separate numbered fields (corrected 2026-09-06 for consistency with the Client Workbook). 7a: Fonagy (reflective functioning: self-mentalization precedes accurate other-mentalization — this is *why* it has to come before 7b, not just be adjacent to it); Prochaska & DiClemente (decisional balance); Oettingen (mental contrasting supplies the Future slot). 7b: same Prochaska/Oettingen mechanism turned outward; Baumrind and Gershoff & Grogan-Kaylor ground the content in documented outcomes, not generic guilt.
8. **Anchor Identity** — cross-link to Identity Installer; Kegan & Lahey's Big Assumption logic — the new script has to run from a secured identity or it collapses under pressure. **Moved before the Desired Script as of 2026-09-06** (was after it in the original design) — see the Sequencing rule below; identity has to be received before the new script is authored, not after.
9. **The Desired Script — Step by Step** — Ecker/Ticic/Hulley (a vague ideal can't out-compete a vivid automatic pattern — needs matched specificity); Fonagy again (the capacity being rehearsed is reflective functioning in the live moment). Now explicitly authored *from* field 8, not toward it.
10. **Holding Both — In the Body** — identical mechanism to both sibling tools: Ecker/Ticic/Hulley, Ogden & Fisher, Fosha, Gendlin.
11. **Out Loud Rehearsal — With a Witness** — Azrin & Nunn's competing-response training requires live practice, not read-and-reflect; this field gives the Witness field an active function. Includes a graduated on-ramp (rehearse alone first if scheduling live feels too exposed) and a note that the witness may be an invested party, not neutral, with an alternate-witness option for rehearsal specifically — both added 2026-09-06.
12. **The Repair Step** — Tronick's rupture-and-repair research: secure attachment is predicted by reliable repair after misattunement, not by its absence. Carries 1 John 1:9 and Luke 15:20 as scriptural grounding (added 2026-09-06) — repair is what a forgiven, secure authority can afford, not a risk a distant judge could take.
13. **Witness** — Johari Window / Proverbs 12:15 / Hebrews 3:13; same as Lie Eliminator's "What Others Observe," but the witness must be a peer adult, never the person the pattern acts on.
14. **Rehearsal / Phase Tracking** — reuses Identity Installer's Active → Integrating → Integrated design directly. Now specifies field-level changes at Integration (Repair Step becomes past-tense testimony; Out Loud Rehearsal drops to spot-check) — added 2026-09-06 to match Identity Installer's own specificity.

14 fields total (matching the Client Workbook's "fourteen sections") — not 15; the Cost field is one wrapped field with two ordered parts, not two separate numbered fields.

## Sequencing rules (don't collapse these)

1. **7a must be completed before 7b, every time** — not just listed in that order on the page. Assessing cost to another person accurately requires the self-mentalizing capacity that 7a builds first (Fonagy), and surfacing the external cost before the internal one risks landing as externally-imposed guilt rather than self-generated motivation (Miller & Rollnick's discrepancy-development principle) — especially dangerous when the pattern being worked *is itself* a punitive/judgment-first script, since guilt-first framing can re-trigger the exact structure the tool is trying to dismantle.
2. **Anchor Identity must be completed before The Desired Script, every time** — added 2026-09-06. Authoring the new behavior before the identity it flows from is willpower, not formation, and inverts this system's own five-layer mechanism (truth received before disciplines sustain). This is not a stylistic preference; a /scrutinize pass caught it as a genuine mechanism-integrity defect in the original design.

## Personal vs. client-facing: what has to differ

- **Personal** (`Coaching Me/Pattern Interrupter/Pattern Interrupter - Personal.md`): first-person, pre-filled with Andrew's actual material where it's already known, blanks left as prompts only where the specific answer is still his to locate. Field names can carry full clinical/theological precision (e.g., "Wound or Gap?" stated exactly as the diagnostic term).
- **Client-facing** (`Coaching/Coaching Preparation/Session — Active/Client Tools/Pattern Interrupter — Client Workbook.md`): generalized to any relational context, not parenting-specific. Every field gets a "What it is / What to do" explainer, matching the Identity Installer Client Workbook's instructional voice. Carries an explicit non-clinical boundary statement and a referral cue (flashbacks/danger-level material → name it to the coach, this tool doesn't cover it). Includes one fully worked fictional example before the blank template, per the sibling workbooks' convention.

## If extending this tool later

- A new entry follows the same 14 fields in order — don't skip 7a-before-7b sequencing, and don't skip Anchor Identity coming before The Desired Script, even for a less loaded pattern.
- If a fourth tool is ever proposed, check first whether it's really a new *layer* (belief / identity / relational script are the three found so far) or just a variant of one of these three — don't create a fourth field-set without first confirming the existing three don't already cover it.
- The phase-tracking system (Active/Integrating/Integrated) is inherited, not reinvented — if Identity Installer's phase design changes, Pattern Interrupter's should be revisited for consistency, and vice versa.
- Before adding any new field, check `_Tool Index.md` for existing overlap first — the original build added Cost and Anchor Identity fields without checking against the already-existing [[04 — Decisional Balance]] and [[05 — Competing Commitment Map]], which a /scrutinize pass caught after the fact. Cross-reference rather than duplicate.
