# Pattern Interrupter — Clinical Basis & Design Rationale

*A dedicated case for the tool's design, not just a field-by-field annotation. [[Pattern Interrupter — Build Prompt]] documents why each field exists and how to extend it; this document establishes that the overall structure is not invented from nothing — it is a working synthesis of named, established clinical protocols for interrupting an automatic behavioral pattern, applied to a relational script rather than the physical habits or addictive behaviors these protocols were originally built for.*

---

## Why this document exists

Neither [[Lie Eliminator - Personal]] nor [[Identity Installer - Personal]] has a separate document like this — their design justification lives embedded inside each personal doc (Lie Eliminator's "Research Basis — Why Each Field Exists"; Identity Installer's "What Psychology Says About Identity Formation"). Pattern Interrupter earns a dedicated treatment for a specific reason: it maps onto one named clinical protocol — Habit Reversal Training — almost component-for-component, more directly than either sibling tool maps onto any single source. That fidelity is worth documenting explicitly rather than folding into a shorter annotation, both so the claim can be checked and so future changes to the tool can be tested against the protocol they're extending.

---

## The primary clinical parent: Habit Reversal Training (Azrin & Nunn, 1973)

Habit Reversal Training (HRT) is the standard behavioral protocol for eliminating an automatic, unwanted behavioral pattern — originally developed for tics and nervous habits, since extended to body-focused repetitive behaviors (hair-pulling, skin-picking) and habitual patterns generally. It has four to five named components. Pattern Interrupter's fields map onto them directly:

| HRT component | What it does clinically | Pattern Interrupter field |
|---|---|---|
| **Awareness training** — response description, response detection, early-warning training | Client learns to describe the habit in detail and, critically, to detect the earliest bodily/situational signal that precedes it — the "premonitory urge" | *This Activates When* + step 1 of *The Old Script* (the body-signal-first structure exists specifically to capture this) |
| **Habit control motivation** | Reviewing the actual inconvenience and cost of the habit, to sustain motivation through the harder work of changing it | *What This Script Gives Me* + the split *Internal/External Cost* fields |
| **Competing response training** | Learning and physically practicing a specific alternative response, performed contingent on the urge or the habit itself, until it competes successfully with the old one | *The Desired Script — Step by Step* |
| **Social support / contingency management** | A significant other is enlisted to prompt the competing response and to note, and reinforce, when the old response occurs | *Witness* |
| **Generalization training** | The competing response is practiced and tested across the different situations and contexts where the habit occurs | *Rehearsal / Phase Tracking* (Active → Integrating → Integrated) |

This is not an incidental resemblance. It is the reason the tool has the shape it has: a document that only named the trigger and the wish would be closer to a values-clarification exercise; naming the trigger, the early-warning signal, a specific competing response, a support person, and a generalization mechanism is what makes it a behavior-change protocol rather than a reflection prompt.

## Supporting protocols filling in the mechanism

**DBT Behavioral Chain Analysis (Marsha Linehan)** — Chain analysis breaks a problem behavior into vulnerability factors, a prompting event, a sequence of intervening links (thoughts, emotions, sensations, actions — each one a potential intervention point), the problem behavior itself, and its consequences. This is the more granular technique behind *This Activates When* and the numbered sequence in *The Old Script*: HRT names "response description" as a component, but chain analysis is what actually teaches a person to decompose a reflex into discrete, interruptible links instead of one indivisible event. Every numbered step in the Old/Desired Script pairing is a chain-analysis link, not a general description.

**Schema Therapy mode work and imagery rescripting (Jeffrey Young)** — Schema therapy names the internalized figure whose voice or behavior is being enacted (a "punitive parent mode," for instance) and works through imagery rescripting: revisiting the scene, and rewriting how it plays out, often installing a different, protective response in place of the original. This is the direct clinical parallel to *Whose Script This Is* (naming the actual source figure, not a generic label) paired with *The Repair Step* (rescripting how the interaction actually resolves). Without this piece, the tool would only document the pattern; with it, the tool is doing the same rescripting work schema therapy does with an internalized figure, applied to a script rather than a belief.

**Marlatt's Relapse Prevention Model** — Marlatt and Gordon's central finding is that a single lapse and a full relapse are not the same event: what determines whether a lapse becomes a relapse is the person's own attributions about it afterward (the Abstinence Violation Effect) — self-blame and "I've already blown it" thinking is what turns a slip into a collapse, not the slip itself. This is the direct basis for two design choices: (1) *Rehearsal/Phase Tracking*'s rule that a relapse in an "Integrated" entry does not revert its status — it opens a new entry for the newly-discovered trigger instead; (2) *The Repair Step*'s function is not only relational (repairing with the other person) but also preventive in Marlatt's sense — naming the misstep honestly and specifically, rather than spiraling into "I'm back to square one," is what keeps a lapse from becoming a full reversion to the old script.

## What "Out Loud Rehearsal — With a Witness" specifically closes

The original design had an honest gap: HRT's competing response training is not a read-and-reflect exercise — in clinical practice, the therapist physically trains and corrects the competing response with the client, live, until it is fluent, before it is ever needed under real pressure. A written document cannot do that on its own. The *Out Loud Rehearsal* field closes part of that gap by giving the *Witness* field an actual function beyond after-the-fact observation: the witness becomes the stand-in for the clinician's live coaching role, present while the Desired Script is spoken aloud and practiced to fluency in a calm moment, not only consulted afterward about which script ran in a real one. This does not fully replace supervised clinical practice, but it is the closest a self-directed tool can come to it, and it is a real, not cosmetic, application of the same mechanism HRT relies on.

## Honest limitations

1. **This is a synthesis, not a single certified manual.** A clinician would recognize each component's ancestry — HRT, chain analysis, schema mode work, relapse prevention — but would not open this document and identify it as any one of them verbatim. The same is true of Lie Eliminator (Beck + Young + Ecker + Allender) and Identity Installer (McAdams + Steele + Young + ACT); this tool follows the same integrative pattern the whole system already uses, now made explicit rather than left implicit.
2. **A document structures the work; it does not supervise it.** Even with the Out Loud Rehearsal field added, there is no real-time correction of the competing response the way a clinician provides. The witness can confirm whether the rehearsal sounds right, but cannot diagnose or refine technique the way a trained clinician would.
3. **No quantified tracking.** Clinical HRT protocols sometimes use frequency counts or urge-intensity ratings to track progress objectively. This tool relies on qualitative phase-shifts (Active → Integrating → Integrated) instead — appropriate for a self-directed formation tool, but a real trade-off against measurable precision.
4. **The theological layer sits alongside, not inside, the clinical mechanism.** Anchor Identity and the broader Covenant Identity Coaching framing are a deliberate integration point consistent with how this entire system operates (biblical content layered onto empirically-grounded structure), not a claim that the clinical protocols themselves are theological. Where the two layers meet is a design choice, not a research finding.
