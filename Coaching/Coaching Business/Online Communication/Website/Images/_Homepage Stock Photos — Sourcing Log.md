# Homepage Stock Photos — Sourcing Log

Four square-cropped, free-commercial-use stock photos selected for the CIC homepage build (Carrd), one per image slot on the page. All under 2MB (largest is 722KB). Andrew's own photo/portrait is reserved separately for the hero slot at the top of the page — not sourced here; that slot is on hold pending a possible AI-generated-from-his-own-photo experiment.

Selection criteria applied: Unsplash License (free for commercial use, no attribution required) only; mood/light search terms rather than category terms; no corporate-coaching stock-people, no religious imagery (churches, pews, crosses, altars — explicitly ruled out by Andrew mid-session, which also eliminated an earlier gilded-cathedral-interior candidate for slot 3), no generic Christian-imagery clichés (open Bible + sunbeam, raised-hands worship). Kept to one consistent warm-earthy-tone family (brick/wood browns, forest greens, sunlit grass) across all four so the set reads as one system rather than four unrelated stock picks — this also means the images do NOT match the "Ink Navy / muted gold" **Quiet Authority** palette spec logged 2026-09-08; they follow the cream/sage-green palette actually visible in the current build screenshots instead. Flagging that mismatch for Andrew to confirm which palette is current.
