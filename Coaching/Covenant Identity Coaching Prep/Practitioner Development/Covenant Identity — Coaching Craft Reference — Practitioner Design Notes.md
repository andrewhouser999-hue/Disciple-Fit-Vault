# Covenant Identity — Coaching Craft Reference — Practitioner Design Notes

*What it is: the method behind the companion Coaching Craft Reference document — why it's structured the way it is, the discipline applied to each entry, and how to extend it when a future `/coaching-trainer`, `/coactive-trainer`, or `/accountability-trainer` session surfaces a new skill worth adding.*

*When used: before adding a new entry to the Coaching Craft Reference, or when evaluating whether a secular coaching concept belongs in CIC's practitioner material at all.*

---

## Why this document exists

Andrew's three coach-training commands each teach a secular coaching skillset through scenario practice — the moment-to-moment judgment of which question to ask, when, and how to phrase it. Each training session surfaced real coaching craft with a genuine question underneath it: *does this transfer into CIC, and if so, how does it change shape?* Answering that question well, repeatedly, across many skills, needed a consistent method rather than ad hoc judgment calls each time — this document is that method, named explicitly so it can be reapplied.

## What this document is not

Not a reading list (that's [[reference_coaching_trainer_reading_list]] in Claude memory — Andrew's personal secular-sourcing bibliography, explicitly scoped to his own practice, not CIC-facing). Not a mechanism reference (that's [[Five Intervention Modalities — Definitions & Deep Elaboration]] for the modalities CIC has already adopted). Not a competency domain structure (that's [[Covenant Identity — Practitioner Competency Framework]]). This document is narrower and more procedural: it is the checklist applied to produce the Coaching Craft Reference's content, so the same rigor is available the next time a skill is added rather than reconstructed from scratch.

## The method — three questions per skill

Every entry in the Coaching Craft Reference answers three questions, in order:

**1. General — what is this, in its own terms?**
State the skill or model as its own tradition describes it, without CIC vocabulary yet. Getting this wrong (importing CIC's frame too early) is how a secular concept gets quietly distorted before it's even been accurately understood.

**2. Coaching craft — what's the actual in-session judgment skill?**
Not the theory, the moment-to-moment discrimination a practitioner has to make live — usually surfaced most clearly by naming what the *wrong* move looks like and why it's tempting. This is the layer `/coaching-trainer`-style scenario practice actually drills, and the layer most secular coaching literature undersells relative to its theory sections.

## The discipline check — run before writing any CIC-application note

**Step A — Check whether this is already directly adopted, not just "parallel."**
Before calling something a parallel or a future-development candidate, search the existing CIC corpus for whether it's already been imported. This check failed once already in producing the companion document: Kegan & Lahey's Big Assumption Experiment and White & Epston's Narrative Re-authoring were both initially logged in [[reference_coaching_trainer_reading_list]] as "structural parallels" needing future translation — when in fact both are already full, named intervention modalities in [[Five Intervention Modalities — Definitions & Deep Elaboration]], complete with scope boundaries and evidence-level grading. That memory file's entries for those two sources are now stale and should be read as superseded by the Coaching Craft Reference. **Lesson:** check [[covenant_identity_file_index]] and the relevant catalog (per [[reference_cic_catalog_documents]]) before assuming a connection is new.

**Step B — Run the claim through CIC's actual architecture, not a generic "Christian coaching" assumption.**
Eight dimensions, surfaced across this cycle's training sessions, that change how a secular skill applies inside CIC specifically:
1. **Bounded telos** — CIC's "forward" direction is fixed (secured covenant identity), unlike most secular models' client-defined destination.
2. **Three-discipline architecture, CBT subordinate** — a secular skill that is fundamentally CBT-shaped (most Life Coaching/GROW content) should not become the first-reached tool; Spiritual Formation and Biblical Counseling lead.
3. **Diagnostic-judgment gate** — CIC's L3 practice level formalizes what other models treat as a general caution: no forwarding before diagnosis.
4. **Wound-vs-formation-gap pacing** — the same secular skill (e.g., Forward and Deepen) applies more or less directly depending on which of these is underneath.
5. **Hard referral / non-clinical boundary** — tighter than general coaching duty-of-care norms; several secular modalities (Schema Therapy, Narrative Therapy) are explicitly scope-limited on import for this reason.
6. **Whose agency is it** — secular autonomy-supportive framing (client-driven) sits under a CIC layer concerned with cooperating with the Spirit's work, not just client self-generated agency.
7. **Lament must not be foreclosed** — a caution with no secular coaching equivalent; several otherwise-sound secular "move to action" skills need an explicit check against this.
8. **Already-adopted-elsewhere check** — Step A above, restated as an architectural dimension in its own right since it's easy to skip under time pressure.

**Step C — Flag the evidence status honestly.**
Every CIC-application note gets one of two tags:
- **(established — [[Doc]])** — cites an actual existing CIC document making this connection or containing this mechanism.
- **(design judgment)** — a reasoned extension, not yet verified against a CIC source. Treat as a hypothesis, not settled doctrine, matching the standard [[Covenant Identity — Connection & Trust-Building Language Reference]] already set for its own new contributors ("not yet cross-verified elsewhere in the CIC set").

Mislabeling a design judgment as established is worse than having fewer established connections — it's exactly the kind of unverified-claim drift the practice's evidence standard exists to prevent.

## How to extend the Coaching Craft Reference

1. Run a `/coaching-trainer`, `/coactive-trainer`, or `/accountability-trainer` session as normal.
2. When a scenario surfaces a skill, model, or contributor not already in the Coaching Craft Reference, apply the three-question method above.
3. Run Step A (already-adopted check) before drafting the CIC-application note — search [[covenant_identity_file_index]] first.
4. Add the new entry to the appropriate Part (1 — Life Coaching Core, 2 — Co-Active, 3 — Accountability Craft) of the Coaching Craft Reference, matching its existing General/Coaching craft/CIC application structure and evidence-flag convention.
5. Walk the indexing checklist below.
