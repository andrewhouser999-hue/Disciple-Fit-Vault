# Covenant Identity — Coaching Craft Reference — Co-Active, Life Coaching & Accountability

*What it is: a practitioner reference translating the secular coaching craft behind Andrew's three coach-training commands (`/coaching-trainer`, `/coactive-trainer`, `/accountability-trainer`) into CIC-specific application — where the skill transfers directly, where it changes shape inside CIC's bounded telos and diagnostic gates, and where it doesn't transfer at all.*

*When used: building in-session question-craft and judgment outside live client work; a refresher before a session where a specific skill (e.g. holding Forward and Deepen, discriminating a defended insight from a real one) is anticipated to matter.*

**Scope boundary — read before use:** this document is not mechanism or theory (that's [[Five Intervention Modalities — Definitions & Deep Elaboration]]) and not domain structure (that's [[Covenant Identity — Practitioner Competency Framework]]). It is the layer underneath both: the moment-to-moment judgment of *which* question, *when*, *phrased how* — the skill a secular coach-training command drills through scenario practice. Two of the contributors below (Kegan & Lahey, White & Epston) are **already directly adopted** as CIC intervention modalities; this document doesn't re-derive their mechanism, only adds the in-session discrimination skill around deploying them that the mechanism document doesn't cover.

**Evidence-flag convention used throughout:** *(established — [[Doc]])* means the CIC connection cites an existing CIC document directly. *(design judgment)* means it's a reasoned extension not yet verified against a CIC source document — treat as a hypothesis to confirm, not settled doctrine, per [[Covenant Identity Coaching — Practice Definition]]'s own standard for flagging non-sourced claims.

## Part 1 — Life Coaching Core (ICF / GROW / Motivational Interviewing / Appreciative Inquiry / Solution-Focused)

### GROW Model (Goal, Reality, Options, Will)

*General:* The most widely taught coaching structure (Whitmore) — sequences a conversation from what the client wants, to what's actually true now, to what could be done, to what they'll actually commit to.

*Coaching craft:* GROW's main failure mode is collapsing stages — jumping from Goal to Will without a clean Reality pass, which produces action plans built on an unexamined picture of the current state.

*CIC application:* CIC's own diagnostic sequence is a theologically-specific, much deeper version of a Reality pass — Affections Discovery, God-Exclusion Map, and Character Wound typing all exist to establish what's actually true before any Options/Will work happens *(established — [[Covenant Identity — Diagnostic Lens Transition Logic]])*. The practical risk for a CIC coach trained in GROW is reflexive: the pull to move to Options too fast is the same pull the diagnostic sequence is built to resist. Where GROW differs sharply from CIC: GROW's Goal is whatever the client names; CIC's eventual "goal" is bounded by the practice's telos (living out of a secured covenant identity), so a GROW-trained coach has to resist treating every client-stated goal as automatically the right target the way secular GROW practice does *(design judgment)*.

### Appreciative Inquiry

*General:* Cooperrider's model — building change from what's already working and life-giving (the "positive core") rather than from deficit/problem analysis; the 4-D cycle (Discover, Dream, Design, Destiny).

*Coaching craft:* Its main skill is resisting the pull toward problem-saturated language even when the client offers it first — asking "tell me about a time this went well" rather than "why does this keep failing."

*CIC application:* Close kinship with Narrative Re-authoring's "unique outcomes" / exception-event search *(established — [[Five Intervention Modalities — Definitions & Deep Elaboration]])* — both refuse to let a deficit story be the only data. The difference: Appreciative Inquiry's positive core is whatever the client already values; CIC's version has to locate the positive core *in what God has already done or is already true*, not just in what the client already likes about themselves — otherwise it risks affirming a false-self strength rather than a true-self one *(design judgment, follows from the Theological-Formation Contributor Stack's grace-forward change theory)*.

### Solution-Focused Brief Coaching

*General:* De Shazer/Berg's model — presupposes the client already has resources and exceptions to the problem; signature tools are the Miracle Question and scaling questions.

*Coaching craft:* Works by assuming competence rather than diagnosing deficit, which shortens the path to action for clients who don't need deep excavation.

*CIC application:* This is the clearest place a secular model's core assumption conflicts with CIC's architecture rather than just needing translation. Solution-Focused deliberately brackets the "why" in favor of "what works" — CIC's diagnostic sequence is built on the opposite premise, that surface behavior change without diagnostic precision just relocates the false identity's symptom elsewhere *(established — [[Covenant Identity Coaching — Theory of Change]], node 2)*. Scaling questions and small-next-step framing remain useful craft at the Phase 4 integration/close stage once diagnostic work is actually done *(established — [[Covenant Identity — Phase 4 Session Tools]])* — the caution is using this model's speed as a reason to skip Phases 1–3.

### Motivational Interviewing (Miller & Rollnick)

*General:* Partnership/acceptance/compassion/evocation as the spirit of the method; OARS skills; change-talk vs. sustain-talk discrimination. Fuller sourcing in [[reference_coaching_trainer_reading_list]] (Claude memory, Andrew's personal practice list).

*Coaching craft:* The specific skill drilled hardest in `/coaching-trainer` and `/accountability-trainer` scenarios this cycle: recognizing sustain talk disguised as fluent insight, and responding to the defense before the content it's protecting.

*CIC application:* Already a named contributor to CIC's Life Coaching discipline *(established — [[research_three_disciplines]], Claude memory)*. The sharpest CIC-specific addition: MI's "roll with resistance" has a harder boundary in CIC than in secular use, because some of what looks like resistance is actually a legitimate Stage 2→3 grief/vision-gap signal that shouldn't be rolled with but named *(established — [[Covenant Identity — Diagnostic Lens Transition Logic]])* — an MI-trained coach has to tell genuine sustain-talk apart from a client correctly working through lament, which MI's own framework doesn't distinguish since it has no lament category.

### Core Listening & Inquiry Disciplines

The seven cross-cutting skills `/coaching-trainer` drills aren't separate models — they're the meta-layer every model above depends on. CIC translation for each:

- **Following emotion before content** — directly continuous with CIC's "read affect that doesn't match content" diagnostic skill *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 1)*.
- **Distinguishing genuine questions from advice/leading questions in disguise** — maps onto CIC's non-directive stance throughout the diagnostic sequence; a leading question in CIC risks supplying the client a covenant-truth conclusion before it's been personally met, which collapses Theory of Change node 5 into assertion rather than encounter *(established — [[Covenant Identity Coaching — Theory of Change]])*.
- **Depth vs. breadth judgment** — this is the Stage 4a/4b differentiation itself, CIC's single most consequential diagnostic call *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 1)*.
- **Separating stated agenda from real presenting issue** — the Wound-Led/Vision-Led entry fork exists precisely because a stated goal ("I want to grow") and the real presenting dependency aren't always the same thing *(established — [[Covenant Identity — Wound-Led vs. Vision-Led — Architecture at a Glance]])*.
- **Recognizing when a question closes vs. opens thinking** — load-bearing for not foreclosing lament; a closed question at the wrong moment can functionally perform the Covenant Authority Lament Caution violation *(established — [[feedback_covenant_authority_lament_caution]], Claude memory)*.
- **Reading incongruence** — the explicit/implicit distinction running through the whole diagnostic layer; this is also exactly the skill [[Covenant Identity — Diagnostic Calibration Log]] exists to track accuracy on over time.
- **Resisting the urge to fix, advise, or reassure** — this is Domain 3's non-anxious presence requirement stated as a secular coaching skill *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 3)*; the CIC-specific stakes are higher, since premature reassurance can also short-circuit a lament the client needs to complete.

## Part 2 — Co-Active (CTI) Skills & Contexts

### Listening (Levels 1–3)

*General:* Level 1 (internal, self-focused), Level 2 (fully on the client), Level 3 (the field between — energy, tension, the unsaid).

*Coaching craft:* Catching your own Level 1 leakage — drafting a clever observation internally — is itself a signal to drop back to Level 2/3.

*CIC application:* Level 3 listening is essentially what CIC's "somatic use of self" domain asks for — treating the coach's own body and reactions as data about the room, not just personal reaction *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 3)*. One CIC-specific addition the Co-Active model doesn't carry: the coach's pre-session practice of asking "what am I carrying today that is mine and not this client's?" is a Level 1 check built into CIC's formation discipline *before* the session starts, not just something to self-correct for mid-session *(established — same document, Domain 6)*.

### Intuition

*General:* Offering a hunch lightly, without attachment to being right, as information for the client to use or discard.

*Coaching craft:* The discipline is in the delivery — "I'm noticing X, does that land?" rather than asserting it as fact.

*CIC application:* Directly relevant to the discernment-vs-avoidance skill drilled this cycle, where a client used CIC's own vocabulary ("listening to my body," "resistance") as a sophisticated defense. Co-Active intuition is offered as a hypothesis the client can reject; in CIC, the coach's intuition sometimes concerns whether the client's own stated spiritual discernment is itself the thing needing examination — which raises the stakes of over-attachment to being right, since getting it wrong risks either colluding with avoidance or implicitly challenging the client's relationship with the Holy Spirit *(design judgment)*.

### Curiosity

*General:* Genuine not-knowing stance; staying longer in inquiry before moving to conclusion or action.

*Coaching craft:* The advice monster (Stanier, below) is curiosity's main enemy — the pull to resolve ambiguity with an answer instead of another question.

*CIC application:* CIC's diagnostic sequence requires sustained curiosity through Stage 1 and 2 before covenant truth is spoken at Stage 3 *(established — [[Covenant Identity — Diagnostic Lens Transition Logic]])* — curiosity isn't just a coaching virtue here, it's load-bearing for diagnostic accuracy, since premature movement to Stage 3 before the false identity is specifically and personally named produces generic declaration rather than targeted declaration *(established — [[Five Intervention Modalities — Definitions & Deep Elaboration]], "What separates it from affirmation")*.

### Forward and Deepen

*General:* One of CTI's Five Skills; the discipline of holding action-orientation and emotional depth simultaneously rather than sequencing one after the other.

*Coaching craft:* The hardest version of this skill — demonstrated in this cycle's training — is fusing both into a single question (e.g., "what would it take to build this plan without leaving anything from that conversation still sitting in you?") rather than asking permission to pause forward motion to address feeling first.

*CIC application:* This is where Siegel's window of tolerance, Levine's titration, and Porges's polyvagal theory become directly operative *(established — [[reference_coaching_trainer_reading_list]], Claude memory; Siegel already seated via [[research_earned_secure_attachment_elements]])*. CIC already has its own version of exactly this skill: the Resourcing & Anchor Establishment "touch and return" pattern *(established — [[Covenant Identity — Resourcing & Anchor Establishment — Practitioner Reference]])* is a structural cousin of Forward-and-Deepen — proactively building a resource so excavation work (Deepen) doesn't have to fully suspend session momentum (Forward). The CIC-specific sharpening: Forward in CIC is never just "what will you do" — it's bounded by whether a wound or a formation gap is underneath (if wound, titrate; if formation gap, more direct forwarding is appropriate) *(established — [[Covenant Identity — Character Wound Diagnostic Tool]], "Before Typing" sections)*.

### Self-Management

*General:* The coach's discipline of setting down their own material, noticing their own reactions as data rather than acting on them, and not making the session about the coach's own need to be helpful, right, or liked.

*Coaching craft:* Noticing when you're impressed by a client's fluency is a Self-Management catch — admiration is data about what the client is doing interpersonally, not permission to reward it with a deeper question.

*CIC application:* This is Domain 6 of the Practitioner Competency Framework almost verbatim — ongoing supervision, personal formation work, the pre-session "what am I carrying" ritual, post-session debrief *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 6; operationalized in [[Covenant Identity — Self-Supervision Template]])*. CIC's version goes further than Co-Active's: Self-Management here includes the floor claim that "a coach can only take a client as deep as the coach has been willing to go themselves" — Co-Active doesn't make this an explicit, non-negotiable precondition for practicing at all *(established — same document, "The floor claim")*.

### The Three Contexts — Fulfillment, Balance, Process

*General:* Fulfillment (values, purpose, vision), Balance (perspective, choice, range of motion), Process (emotion, energy, the body, metaphor) — identifying which context is live and responding from it.

*Coaching craft:* Misreading which context is live is a common novice error — responding to a Process moment (raw emotion) with a Balance move (reframing options) short-circuits what's actually happening.

*CIC application:* Rough correspondence, not an equivalence: Fulfillment maps loosely onto Stage 2/3 (false covenant object naming, covenant truth) *(design judgment)*; Process maps closely onto Stage 4b's implicit/somatic work *(established — [[Covenant Identity — Affections Discovery — In-Session Protocol]]'s somatic observation layer)*; Balance has no clean CIC equivalent, since CIC doesn't treat "perspective/choice" as its own standalone context the way CTI does — in CIC, what looks like a Balance conversation (weighing options) is usually either premature Stage 4a work or a sign the diagnostic sequence hasn't actually reached the real presenting issue yet *(design judgment)*.

### Being vs. Doing

*General:* Surfacing the identity question underneath a behavioral one — "who are you" rather than "what will you do."

*Coaching craft:* The tell is often not an emotional crack but its absence — unusual composure or over-analysis on a decision disproportionate to its emotional register, as demonstrated in this cycle's partner-track/own-practice scenario.

*CIC application:* This is, in a real sense, CIC's entire organizing move stated in secular coaching vocabulary — the whole model exists to answer a Being question (who the client actually is in covenant with God) rather than stopping at Doing-level behavior change *(established — [[Covenant Identity Coaching — Manifesto]], telos)*. The difference: Co-Active's Being question is open-ended (whoever the client discovers themselves to be); CIC's Being question has a specific target already named by the model (secured covenant identity), which is why the practice is diagnostic rather than purely exploratory *(established — [[Covenant Identity Coaching — Practice Definition]])*.

## Part 3 — Accountability Craft (`/accountability-trainer`'s knowledge base)

### Locke & Latham — Goal Quality

*General:* Specificity, genuine commitment, and feedback precede effective accountability — a vague or unowned goal can't be held accountable to meaningfully.

*Coaching craft:* Checking goal quality *before* holding someone accountable to it is the step most often skipped under time pressure.

*CIC application:* Directly operative in CIC's intake system — the Airtable `Confirmed Goal` field exists precisely so a goal is verified, not assumed, before tracking begins *(established — [[Covenant Identity — Airtable Schema Spec]])*. CIC's specificity bar is even higher than Locke & Latham's: a false identity must be named "specifically and personally" not generically, which is the diagnostic-layer version of goal specificity *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 1)*.

### Gollwitzer — Implementation Intentions

*General:* If-then planning ("when X happens, I will do Y") outperforms vague intention; "going public" about a commitment can backfire by substituting the social reward for the actual behavior.

*Coaching craft:* The skill is specificity of *when* and *exactly what*, not just *what*.

*CIC application:* CIC already uses this mechanism without naming Gollwitzer — Domain 4 of the Practitioner Competency Framework instructs coaches to "assign commitments as specific implementation intentions (when, exactly what) rather than vague aspirations" *(established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 4 — this document supplies the research attribution that domain was already using unattributed)*. The going-public backfire effect is a live caution for any between-session tool with a social/accountability-partner component *(design judgment, no CIC document yet addresses this specifically)*.

### Kegan & Lahey — Competing Commitments / Big Assumption

*General:* Repeated non-completion is diagnostic of a hidden competing commitment protecting against a feared outcome, not a motivation deficit; the 4-column map surfaces it, a Big Assumption Experiment tests it.

*Coaching craft:* The specific discrimination drilled this cycle — telling a genuinely fluent, well-earned insight apart from fluency itself functioning as the defense, which requires addressing the explaining-as-behavior before the content it's protecting.

*CIC application:* **Already a full CIC intervention modality**, not a parallel to build toward *(established — [[Five Intervention Modalities — Definitions & Deep Elaboration]], modality 5, including the complete four-column architecture and theological convergence note)*. What this document adds on top of that existing mechanism reference: the in-session judgment skill of recognizing when a client's account of their own Big Assumption has become too fluent to be live material, and responding to the fluency itself (an MI-adjacent sustain-talk read) before re-running the experiment logic. *Correction note: an earlier version of this cross-reference, logged in [[reference_coaching_trainer_reading_list]] (Claude memory), undersold this as "would need theological translation" — that memory entry should be read as superseded by this one.*

### Ryan & Deci — Self-Determination Theory

*General:* Autonomy, competence, and relatedness as the three basic psychological needs; autonomous vs. controlled motivation.

*Coaching craft:* Diagnoses why a stated commitment isn't generating real follow-through — often because it was externally imposed rather than genuinely endorsed.

*CIC application:* The relatedness need is the closest fit, resonating with CIC's earned-secure-attachment foundation *(established — [[research_earned_secure_attachment_elements]])*. More specifically useful as a cross-check: SDT's autonomous/controlled distinction gives CIC a secular-vocabulary way to ask whether a client's spiritual commitments are genuinely internalized or compliantly performed — a question CIC needs to ask regardless of this source, since compliance masquerading as transformation is a live risk the model already guards against via the spiritual-bypassing diagnostic *(design judgment, connecting to established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 1, "spiritual bypassing")*.

### Gallwey — Inner Game (Self 1 vs. Self 2, Performance = Potential − Interference)

*General:* Self 1 (the internal critic/judge) interferes with Self 2 (the body's natural, already-capable performer); compassionate, judgment-free attention outperforms harsh correction.

*Coaching craft:* Naming Self 1's interference without agreeing with its content is the core move — not arguing with the inner critic, just reducing its grip.

*CIC application:* A striking structural echo of CIC's own governing frame — "false self governing from below, covenant truth meeting it, Spirit forming the true self into being" *(established — [[Covenant Identity Coaching — Practice Descriptions (Three Forms)]])* is close to Gallwey's Self 1 (interference) / Self 2 (true capability) architecture, just with a theological rather than performance-psychology account of why the interference exists and what resolves it. Gallwey is not a cited CIC contributor and this parallel hasn't been cross-verified elsewhere in the CIC set *(design judgment — flagged the same way [[Covenant Identity — Connection & Trust-Building Language Reference]] flags its own new contributors)*. Worth naming because it supplies a secular-coaching-compatible way to describe the mechanism to a client or peer who isn't yet tracking the theological frame, without smuggling in performance-psychology's self-actualization telos in place of CIC's covenant one.

### Fogg — Behavior Design (B = MAP)

*General:* Behavior = Motivation × Ability × Prompt; repeated failure often signals an ability or design problem, not a motivation problem.

*Coaching craft:* Before increasing accountability pressure, check whether the commitment was ever actually executable given the client's real ability and environment.

*CIC application:* A useful discipline check before CIC's own between-session tool assignment — Domain 4 already warns against assigning "vague aspirations," and Fogg's ability/prompt axis gives a concrete diagnostic for *why* a specifically-worded commitment still didn't land (wrong ability assumption, missing environmental prompt) rather than assuming it must be a motivation or spiritual-resistance problem *(design judgment, extending established — [[Covenant Identity — Practitioner Qualities & Skills for the Work]], Domain 4)*.

### Cloud — Corner 4 / Secondary Gain

*General:* Full acceptance plus full honesty (Corner 4 of Cloud's relational-conditions model) is the only quadrant where real change happens; secondary gain is the invisible benefit a stuck pattern provides.

*Coaching craft:* Checking for secondary gain before assuming a client simply lacks willpower or clarity.

*CIC application:* Secondary gain is conceptually identical to CIC's hidden competing commitment / false covenant object — both name an invisible payoff maintaining a pattern the client consciously wants to change *(design judgment, structural overlap with — [[Five Intervention Modalities — Definitions & Deep Elaboration]], modality 5)*. Corner 4's "full acceptance + full honesty" is a secular-psychology restatement of the alliance condition CIC's Discovery Call and designed-alliance work are built to establish before diagnostic work opens *(design judgment)*.

### Brown — Shame Resilience

*General:* Shame ("I am bad") vs. guilt ("I did something bad"); vulnerability as the birthplace of connection; sympathy-as-collusion vs. empathy-as-presence. Fuller sourcing in [[reference_coaching_trainer_reading_list]].

*Coaching craft:* The specific skill drilled this cycle — naming a client's bid for reassurance ("right?") rather than granting or ignoring it.

*CIC application:* The shame/guilt distinction closely parallels CIC's indwelling-sin-and-repentance mechanism, which already distinguishes identity-collapse shame responses from genuine repentance and builds the Witnessing Repentance tool specifically to avoid triggering the former *(established — [[project_cic_indwelling_sin_repentance_mechanism]], Claude memory; flags Hermit wound-type as highest shame-collapse risk)*. Brown's framework is secular and shouldn't be cited as doctrinal grounding for that mechanism — it's a useful cross-check vocabulary, not a source for it *(design judgment)*.

### Goldsmith — Active Questions / Feedforward

*General:* "Did I do my best to..." active questions shift responsibility onto effort; feedforward asks what to do differently going forward rather than relitigating the past.

*Coaching craft:* Reusable, low-overhead accountability check-in format.

*CIC application:* Technique-level fit for between-session structures like the Reckoning Pattern's flagged formation card *(design judgment — [[project_reckoning_pattern_future_dev]], Claude memory, not yet built)*; limited theological content, so it supplies format rather than substance.

### Stanier — The Advice Monster

*General:* Seven short questions built to interrupt reflexive advice-giving; staying curious longer than feels comfortable.

*Coaching craft:* "And what else?" as a simple, repeatable discipline against closing an inquiry too early.

*CIC application:* Directly supports CIC's non-directive stance at Stage 1–2, where supplying a conclusion before the client personally names their own false identity undermines the diagnostic layer's whole premise *(established — [[Covenant Identity — Diagnostic Lens Transition Logic]])*. Track-agnostic fluency tool — no CIC-specific adaptation needed beyond this.

### Reynolds — Thinking-Level Accountability

*General:* The ABCD model; "what is that doing for you?"; discomfort as data rather than something to resolve quickly.

*Coaching craft:* Already the direct source of the defense-targeting question type drilled this cycle (distinct from content-targeting).

*CIC application:* Pairs with CIC's flagged Layer 11/12 implicit-belief session tool, which is concerned with exactly this kind of automatic internal narration *(design judgment — [[project_layer11_12_session_tool_future_dev]], Claude memory, tool not yet built)*; Reynolds's frame is cognitive, CIC's is covenantal, so this is a craft-technique import, not a theological one.

### Flores — Promise Structure

*General:* A genuine promise requires speaker, listener, specific action, and time; "I'll try" is a performative, not sincere, assertion.

*Coaching craft:* Catching hedge words ("doable," "I'll try") as data about commitment quality, demonstrated this cycle in the mentor-outreach goal-setting scenario.

*CIC application:* Structural cousin of Targeted Declaration Work's insistence on *specific, personal* language over generic affirmation — both treat vague language as diagnostically meaningful rather than a harmless shorthand *(design judgment, parallel to established — [[Five Intervention Modalities — Definitions & Deep Elaboration]], modality 1)*.

### ICF Core Competencies

*General:* The professional ethics and competency floor underlying all coaching, revised periodically; PCC/MCC competency markers.

*Coaching craft:* Baseline re-grounding after time away from formal practice.

*CIC application:* CIC's own Practitioner Competency Framework is an explicit CIC-specific elaboration built on top of this floor, not a replacement for it *(established — [[Covenant Identity — Practitioner Competency Framework]])* — worth re-reading the ICF source directly since competency language has shifted since Andrew's original certification.
